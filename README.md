# nxrobins.github.io

Personal portfolio — Nigel Xavier.

## Deploy

Push to `main` on a repo named `nxrobins.github.io`. GitHub Pages serves automatically.

## Local preview

```bash
# any static server works
npx serve .
# or
python -m http.server 8000
```

## Stack

- Static HTML/CSS/JS
- JetBrains Mono + Inter (Google Fonts CDN)
- Zero build step, zero dependencies
